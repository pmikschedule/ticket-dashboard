================================================================================
 이슈 트래킹 에이전트 — 오프라인 꾸러미 (설치 불필요)
================================================================================

 인터넷도 pip 도 없는 윈도우에서 **압축만 풀어 실행**하는 꾸러미입니다.
 설치 프로그램을 돌리지 않고, 가상환경도 만들지 않고, 아무것도 시스템에
 등록하지 않습니다. 이 폴더를 지우면 흔적 없이 사라집니다.


--------------------------------------------------------------------------------
 0. 필요한 것 — 파이썬 하나뿐입니다
--------------------------------------------------------------------------------

 명령 프롬프트(cmd)를 열고 확인하세요:

     python --version

 3.10 / 3.11 / 3.12 / 3.13 / 3.14 중 하나가 나오면 그대로 진행하면 됩니다.
 다섯 버전 모두 이 꾸러미에 들어 있습니다.

 "찾을 수 없습니다" 가 나오면 아래도 해 보세요:

     py --version
     "C:\Program Files\Python312\python.exe" --version

 그래도 없으면 파이썬이 필요합니다. 설치가 안 되는 환경이라면
 python.org 의 **embeddable package**(zip, 설치 불필요)를 받아 이 폴더 안에
 풀어 쓸 수 있습니다. 담당자에게 문의하세요.

 아웃룩은 **실행해 두세요.** 꺼져 있으면 프로필 선택 창에서 멈춥니다.


--------------------------------------------------------------------------------
 1. 압축 풀기
--------------------------------------------------------------------------------

 아무 폴더에나 풉니다. 경로에 한글이나 공백이 있어도 됩니다.

     예) C:\ticket-agent\

 풀고 나면 이런 모양입니다:

     run.py            실행 진입점
     run-agent.bat     더블클릭용
     .env.example      설정 예시
     src\              소스
     lib\              라이브러리 (건드리지 마세요)
     READ-ME-FIRST.txt 이 파일


--------------------------------------------------------------------------------
 2. 설정 — 채울 값은 두 개뿐입니다
--------------------------------------------------------------------------------

 .env.example 을 복사해 .env 로 이름을 바꾸고 메모장으로 엽니다.
 (run-agent.bat 을 그냥 실행하면 이 과정을 대신 해 줍니다)

   SUPABASE_URL=https://dftqwkvhqjgwrfidsmwc.supabase.co

   SUPABASE_SERVICE_KEY=      <- Supabase 대시보드
                                 Project Settings > API keys > Secret key
                                 sb_secret_ 로 시작합니다.
                                 sb_publishable_ 는 웹용이라 안 됩니다.

 나머지는 그대로 둡니다. 특히:

   GEMINI_API_KEY=            <- 비워 두세요. 웹 설정 화면에 등록한 키를 씁니다.
   AGENT_MAIL_BACKEND=auto    <- 윈도우에서는 자동으로 outlook 이 됩니다.
   AGENT_SEND_MODE=display    <- 회신은 사람이 확인하고 보냅니다.
   OUTLOOK_FOLDER=받은 편지함/요청

 OUTLOOK_FOLDER 에 적은 폴더가 없다면 '받은 편지함' 으로 바꾸세요.
 하위 폴더는 / 로 구분합니다.

 ※ SUPABASE_SERVICE_KEY 는 권한 검사를 우회하는 키입니다.
    이 파일 밖으로 내보내지 마세요.


--------------------------------------------------------------------------------
 3. 실행
--------------------------------------------------------------------------------

 run-agent.bat 을 더블클릭하거나, 명령 프롬프트에서:

     cd C:\ticket-agent
     python run.py doctor        <- 점검 (먼저 이것부터)
     python run.py collect       <- 한 번만 수집
     python run.py run           <- 상시 실행

 doctor 가 이렇게 나오면 정상입니다:

     [i] Gemini 키 출처 - 설정 화면 (...)
     [O] Supabase - 연결 성공
     [O] 메일 백엔드 - '받은 편지함/요청' 접근 성공
     [O] Gemini API - 모델 'gemini-2.5-flash' 사용 가능

 처음에는 .env 의 SCAN_LIMIT 을 5 정도로 낮춰 몇 건만 돌려 보세요.


--------------------------------------------------------------------------------
 4. 자주 나오는 문제
--------------------------------------------------------------------------------

 "이 꾸러미에 파이썬 3.x 용 라이브러리가 없습니다"
   -> 담긴 것은 3.10~3.14 입니다. 더 새 버전이면 담당자에게 알려 주세요 —
      꾸러미를 다시 만들어야 합니다. 라이브러리를 갈아 끼워 쓸 수는 없습니다.
      급하면 이 PC 에 있는 다른 파이썬으로 실행해 보세요:
          py -3.12 run.py doctor

 "메일 백엔드 ❌"
   -> 폴더 이름이 다르거나, 아웃룩이 꺼져 있거나, 프로필 선택 창에서
      멈춰 있습니다. 아웃룩을 먼저 띄우고 메일이 보이는지 확인하세요.

 "Gemini 키 출처 - agent/.env"
   -> 웹 설정 화면의 등록이 안 물린 것입니다. .env 의 GEMINI_API_KEY 가
      비어 있는지 확인하세요.

 수집은 되는데 티켓이 안 보임
   -> 웹의 '스크리닝' 화면을 보세요. 제외된 메일도 판정 근거가 남습니다.


--------------------------------------------------------------------------------
 5. 상시 실행 (작업 스케줄러)
--------------------------------------------------------------------------------

 ※ 반드시 "사용자가 로그온할 때만 실행" 을 고르세요.

    "로그온 여부에 관계없이 실행" 을 고르면 아웃룩 COM 을 쓸 수 없는
    세션에서 돌게 되고, 오류 없이 **아무 메일도 수집되지 않습니다.**

  1) 작업 스케줄러 > 작업 만들기
  2) 일반 > "사용자가 로그온할 때만 실행"
  3) 트리거 > 로그온할 때
  4) 동작 > 프로그램 시작
       프로그램:   C:\ticket-agent\run-agent.bat
       시작 위치:  C:\ticket-agent
  5) 조건 > "AC 전원이 켜져 있는 경우에만 시작" 해제
